Privacy Policy

Last updated: September 19, 2026

The short version: Security Copilot connects to your GitHub account to help you find and fix security vulnerabilities. We only access what you explicitly give us permission to access, we do not sell your data, and our AI runs on our own server, your code is never sent to OpenAI or any third-party AI provider.

Who we are

Security Copilot is an open-source tool built and maintained by Adewole Oluwapelumi. The hosted version runs at securitycopilot.com.ng. You can also self-host the entire stack using the instructions in the GitHub repository.

For privacy questions, contact us at pelumiade92@gmail.com.

What we collect and why

GitHub account information

When you sign in with GitHub, we receive your GitHub username, display name, and email address. This is used to identify your account and send you notifications about security findings.

Repository information

We fetch the list of repositories your GitHub account has access to so you can choose which ones to monitor. We only actively monitor repositories you explicitly select.

Security findings

For repositories you choose to monitor, we pull security alerts from GitHub's own security features: CodeQL code scanning alerts, Dependabot vulnerability alerts, and Secret Scanning alerts. This data comes directly from GitHub's API and is stored in our database to power the dashboard.

AI analysis results

When you request an AI analysis of a finding, we send the finding's metadata (title, severity, description, affected file and line number) to our AI model. The result — a plain-English explanation of the vulnerability and a proposed fix — is stored and shown on your dashboard.

How the AI works

Your code stays on your infrastructure. The AI model (DeepSeek Coder, running via Ollama) runs on our own server in Oracle Cloud. When you analyze a finding, we send the finding metadata and the relevant code snippet to our server. Nothing is sent to OpenAI, Anthropic, or any external AI API.

The code snippet sent for analysis is the specific fragment identified in the security alert, not your entire repository. We do not store code snippets after the analysis is complete, only the AI's output (what the vulnerability is, why it matters, and how to fix it).

What we do not do

  • We do not sell your data to anyone, ever.
  • We do not share your repositories, findings, or analysis results with third parties.
  • We do not store your source code only security alert metadata and AI analysis results.
  • We do not use your data to train AI models.
  • We do not access repositories you have not explicitly selected for monitoring.
  • We do not retain data after you delete your account.

GitHub OAuth access

When you connect your GitHub account, you grant Security Copilot the following permissions:

  • Read access to your profile (username, email)
  • Read access to your repositories
  • Read access to security alerts (CodeQL, Dependabot, Secret Scanning)
  • Write access to create pull requests with proposed fixes
  • Write access to create workflow files (for enabling CodeQL)

You can revoke this access at any time from your GitHub account settings under Authorized OAuth Apps.

Data storage and security

Your data is stored in a PostgreSQL database hosted on Oracle Cloud (South Africa Central region). GitHub access tokens are encrypted at rest using AES-256-GCM before being stored. Session tokens use signed JWTs with a 24-hour expiry.

Security Copilot is a personal project and is provided as-is. If you have particularly sensitive repositories, we recommend self-hosting the application on your own infrastructure. Full setup instructions are available in the README.

Data retention

We retain your data for as long as you have an active account. If you stop using Security Copilot, your data remains stored unless you request deletion. To delete your account and all associated data, email pelumiade92@gmail.com and we will process your request within 7 days.

Self-hosting

Security Copilot is fully open source under the MIT License. If you prefer complete control over your data, you can run the entire stack on your own infrastructure. The source code, including setup instructions, is available at github.com/Lhilove/security-copilot.

When self-hosting, no data is sent to our servers. You are responsible for the security of your own deployment.
